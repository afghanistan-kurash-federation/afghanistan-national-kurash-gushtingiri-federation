این سایت یک فایل مستقل است و برای GitHub Pages ساخته شده است.

برای استفاده:
1) فقط فایل index.html را در ریشه Repository آپلود کنید.
2) Commit directly to main را انتخاب کنید.
3) در Settings > Pages، گزینه Deploy from a branch و سپس main / (root) را انتخاب کنید.
4) Save کنید.

نام‌ها، لوگوها، عکس‌ها، ایمیل و شماره‌های نمونه باید قبل از معرفی رسمی با اطلاعات تأییدشده جایگزین شوند.
