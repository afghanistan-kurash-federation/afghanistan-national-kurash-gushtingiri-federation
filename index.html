ماموریت

توسعه و معرفی کورش و گوشتینگیری و ایجاد مرجع منظم برای اطلاعات فدراسیون‌ها و اعضا.

  • معرفی ساختار فدراسیون
  • ثبت مربیان و داوران
  • معرفی ورزشکاران و رویدادها
  • آرشیو اسناد و رسانه‌ها

نسخه وب اولیه

این سایت Static است و برای GitHub Pages مناسب است؛ برای شروع سرور یا دیتابیس پولی لازم ندارد.

  • واکنش‌گرا برای موبایل و کامپیوتر
  • بدون Node.js و npm
  • قابل توسعه برای پنل مدیریت در آینده
  • مناسب افزودن عکس، سند و مشخصات افراد
